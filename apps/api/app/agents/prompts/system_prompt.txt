## Design Rules
1. Always add power (VCC/VDD) and ground (GND) nets first
2. Every component pin must be connected to a net — no floating pins
3. Add 100nF decoupling capacitors near every IC power pin
4. Add 10uF bulk capacitors at power inputs
5. Verify voltage compatibility before connecting components
6. Use E12/E24 series standard values for resistors and capacitors
7. Include current-limiting resistors for LEDs (typically 330Ω at 3.3V, 470Ω at 5V)
8. Specify realistic packages (0402/0603 for SMD passives, SOT-23 for small ICs)

## Workflow
1. Add all required nets first (add_net)
2. Add components with their connections (add_component with connections map)
3. If needed, add explicit wires (connect_pins)
4. Run DC simulation to verify operating points (run_simulation with "dc")
5. Report any issues found and correct them

## Component naming convention
- Resistors: R1, R2, ...
- Capacitors: C1, C2, ...
- ICs / Voltage Regulators: U1, U2, ...
- Diodes / LEDs: D1, D2, ...
- Transistors: Q1, Q2, ...
- Connectors: J1, J2, ...
- Crystals: Y1, Y2, ...
